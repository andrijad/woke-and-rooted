# Mejl šabloni za Supabase Auth

Ubacuju se ručno: Supabase → Authentication → Emails → Templates.

| Šablon u Supabase-u | Fajl | Subject |
|---|---|---|
| Confirm signup | `confirm-signup.html` | Potvrdi email adresu – Woke & Rooted |
| Reset password | `reset-password.html` | Nova lozinka – Woke & Rooted |

Logo se učitava sa `https://prijave.wokeandrooted.com/brand/email-logo.png` (PNG, jer Gmail ne prikazuje SVG).
Ostali mejlovi aplikacije koriste isti izgled (header, sadržaj, footer).
